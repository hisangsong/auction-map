# 전국 아파트 실거래가 지도 🏢

전국 지도 위에 국토교통부 공식 아파트 매매 실거래가를 표시하는 웹 앱입니다.

- **지도**: 카카오맵 (주소 → 좌표 자동 변환)
- **데이터**: 국토교통부_아파트 매매 실거래가 API (공공데이터포털, 무료)
- **기능**: 지역·월 선택, 아파트별 마커, 거래 목록, 상세 거래내역

## 구조

```
브라우저(index.html) → Vercel 서버함수(/api/deals.js) → 국토부 API
```

서버함수가 인증키를 숨기고, XML을 JSON으로 변환해 전달합니다.

## 설정 (중요)

1. 공공데이터포털(data.go.kr)에서 "국토교통부_아파트 매매 실거래가" API 활용신청 → 인증키(Decoding) 발급
2. Vercel 프로젝트 설정 → Environment Variables 에 `DATA_GO_KR_KEY` = 발급받은 인증키 등록
3. 재배포(Redeploy)
