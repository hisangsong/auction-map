# 서울 법원경매물건 지도 ⚖️

서울시 법원경매 물건을 지도에 표시하는 웹 앱입니다.

- **지도**: 카카오맵 (소재지 → 좌표 자동 변환)
- **데이터**: `data.json` (서울시 법원경매 실데이터, 엑셀에서 변환)
- **기능**: 구(區) 선택, 용도별 필터, 물건 마커(최저매각가), 목록, 상세정보

## 데이터 갱신 방법

새 엑셀(`서울시_법원경매물건.xlsx`)을 받으면, 변환 스크립트로 `data.json`을 다시 만들어 교체하고 push 하면 됩니다.
컬럼: 사건번호 / 법원 / 소재지 / 용도 / 감정평가액 / 최저매각가격 / 최저매각가율 / 유찰횟수 / 매각기일 / 시군구 등

## 구조

정적 사이트입니다. `index.html` 이 `data.json` 을 읽어 지도에 표시합니다. (API 키·서버 불필요)

## 배포

GitHub에 push 하면 Vercel이 자동으로 배포합니다.
