# 전국 경매물건 지도 🏠

전국 지도 위에 법원 경매 물건을 표시하는 웹 앱입니다.

- **지도**: 카카오맵
- **기능**: 물건 마커(최저가 표시), 목록, 종류별 필터, 상세정보 카드
- **데이터**: 현재는 샘플 데이터 (전국 주요 도시 18건)

## 설정

`index.html` 안의 `KAKAO_APP_KEY` 에 카카오 개발자센터에서 발급받은
JavaScript 키를 넣어야 지도가 표시됩니다.

## 물건 추가/수정

`index.html` 의 `물건목록` 배열에 항목을 추가하면 됩니다. (금액 단위: 만원)

## 배포

GitHub에 push 하면 Vercel이 자동으로 배포합니다.
